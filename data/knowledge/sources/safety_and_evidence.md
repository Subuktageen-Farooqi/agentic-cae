# Image evidence

An unscaled reference image can support observations about visible topology, proportions, interfaces, and apparent mechanisms. It cannot establish precise dimensions, hidden features, material properties, load capacity, or manufacturing tolerances. Keep observed features separate from inferences and user-confirmed engineering facts.

# Geometry and analysis evidence

A valid single solid with the expected bounding dimensions establishes limited geometry evidence. It does not establish adequate strength, stiffness, fatigue life, vibration durability, manufacturability, or safety. A completed linear static solve answers only the modeled load case, material, supports, mesh, and assumptions.

# Missing evidence

When a retrieved source does not address the current decision, state that evidence is insufficient and ask a focused question. A retrieved example or guideline is context, not a user requirement. Acceptance criteria must come from the user or an identified engineering source.
