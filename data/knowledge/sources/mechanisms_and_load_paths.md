# Constraints and motion

A useful first question is which motion the design must allow and which motion it must prevent. A fixed support idealizes all translational and rotational degrees of freedom as constrained. Pin and sliding interfaces intentionally retain selected motion. Over-constraining a real assembly can make tolerance variation create unintended assembly stress.

# Load paths

Sketch a continuous path from each applied load, through the part, joints, and fasteners, to the support. Abrupt section changes, unsupported offsets, and loads far from a support can raise bending and local stress. A simple bracket concept should identify the supported interface and loaded interface before choosing detailed geometry.

# Cantilever example

A cantilever support arm is a useful integration example because its fixed end and loaded end are geometrically distinct. It is still an idealization: real fasteners, contact, support compliance, and local constraint effects require more detailed treatment before engineering release.
